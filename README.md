# 📚 Library Room Booking and Availability System

A web-based application developed as a Final Year Project to simplify library room reservations through an online booking platform.

## ✨ Features
- User registration and authentication
- Role-based access (Student, Staff & Admin)
- Real-time room availability
- Online room booking and cancellation
- Booking history and notifications
- Room issue reporting
- Admin dashboard for managing users, rooms, and bookings
- Booking reports and room usage analytics

## 🛠️ Tech Stack
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP
- Visual Studio Code

## 🎯 Project Objectives
- Digitalize the library room booking process
- Reduce booking conflicts through availability checking
- Improve room management efficiency
- Provide a centralized platform for users and administrators
